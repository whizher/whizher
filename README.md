## Featured projects

### [Atlas Ekonomi Pontianak](https://github.com/whizher/kalbar-economic-atlas)

An independent, Indonesian-language atlas exploring prices, employment, and welfare in **Kota Pontianak** using official BPS data.

It presents six indicators with annual trends, accessible charts, equivalent data tables, source references, and JSON downloads. The site supports light and dark themes and mobile layouts.

[Explore the live atlas](https://whizher.github.io/kalbar-economic-atlas/) · [View the source](https://github.com/whizher/kalbar-economic-atlas)

### [Economics Toolkit](https://github.com/whizher/economics-toolkit)

Five practical calculators for percentage change, compound annual growth rate, inflation and purchasing power, real versus nominal values, and compound-growth projections.

Each calculator shows its formula and runs locally in the browser. The toolkit supports phones and desktops, keyboard navigation, and light and dark themes.

[Open the live toolkit](https://whizher.github.io/economics-toolkit/) · [View the source](https://github.com/whizher/economics-toolkit)
